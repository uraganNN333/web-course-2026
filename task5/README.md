# Лаб 5. Игра Simon

Компьютер показывает последовательность цветных кнопок, игрок повторяет; каждый раунд добавляется один шаг. Показ сделан через `async/await` и `setTimeout`, все таймеры останавливаются при ошибке и перезапуске, есть звук через `AudioContext`.
Запуск: открыть `index.html` в браузере, нажать «Старт».
