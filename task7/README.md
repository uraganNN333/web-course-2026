# Лаб 7. Лента постов с бесконечным скроллом

Посты загружаются порциями по 10 с `jsonplaceholder.typicode.com` через `fetch` + `async/await` (с `try/catch`), новые подгружаются при прокрутке вниз (`IntersectionObserver`). Есть поиск по заголовку с дебаунсом 300 мс по уже загруженным данным, индикатор загрузки, сообщение об ошибке с кнопкой «Повторить» и сообщение «Больше постов нет».
Запуск: открыть `index.html` в браузере (нужен интернет).
