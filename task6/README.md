# Лаб 6. Игра «Змейка» на Canvas

Классическая змейка на поле 20×20: управление стрелками, яблоки, рост, столкновения со стеной и хвостом, счёт и рестарт без перезагрузки. Игровой цикл на `requestAnimationFrame` с шагом по времени (150 мс), логика (`update`) отделена от отрисовки (`draw`).
Запуск: открыть `index.html` в браузере и нажать стрелку.
