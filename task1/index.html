02Что умею делать

Очистка и подготовка данных

Строю ETL-процессы: собираю данные из сырых источников, убираю дубликаты и транзакции без ID, проверяю типы. Использую векторизованные вычисления, чтобы код работал быстро и не расходовал память.

Статистика и проверка гипотез

Проверяю, действительно ли различия в метриках не случайны: подбираю тест (например, T-критерий Уэлча), считаю p-value и показываю результат на понятных графиках с KDE-распределениями.

Продуктовая аналитика

Работаю с юнит-экономикой и продуктовыми метриками, делаю RFM-анализ, оцениваю удержание клиентов (Retention) и превращаю выводы в рекомендации по бюджету и рассылкам.

Базовое машинное обучение

Строю модели на Scikit-learn (Random Forest), создаю признаки из поведения пользователей и оцениваю качество через ROC-кривую и AUC-ROC. Продолжаю углублять знания.

SQL и хранилища данных

Пишу сложные запросы: оконные функции, CTE, продвинутые объединения. Знаком с принципами проектирования хранилищ — Kimball и Data Vault.

Объяснение сложного простым языком

Благодаря опыту преподавания умею донести технические выводы до людей без технического бэкграунда и аргументированно защитить решение.

04Проекты и исследовательский опыт

Предиктивная аналитика и статистическое тестирование для E-Commerce

Задача: понять, различаются ли средние чеки, и как удержать клиентов магазина.

  • Python
  • Scikit-learn
  • SciPy
  • Pandas
  • Seaborn
  • Random Forest
  • LaTeX
  • Провёл комплексный анализ данных электронной коммерции. Разработал ETL-процесс для очистки датасета от транзакций без ID.
  • Применил T-критерий Уэлча для проверки гипотезы о различии средних чеков (AOV); доказал статистически значимую разницу (p-value < 0.001) и визуализировал результаты через KDE-распределения.
  • Сгенерировал признаки на основе исторического поведения (RFM-анализ) и на базовом уровне построил предиктивную модель оттока (Retention) на базе Random Forest.
  • Оценил качество модели с помощью ROC-кривой, достигнув показателя AUC-ROC = 0.79.
  • Дал рекомендации по внедрению ML-модели для рассылки retention-скидок и перераспределению бюджета.
  • AUC-ROC 0.79
  • p-value < 0.001
  • Рекомендации по бюджету
