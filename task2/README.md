# Лаб 2. Адаптивный лендинг «МатКод»

Лендинг репетитора: Mobile First, три брейкпоинта (до 767, 768–1199, от 1200 px), крупная сетка на CSS Grid, компоненты на Flexbox, меню-гамбургер и форма обратной связи.
Запуск: открыть `index.html` в браузере. Макет разработан самостоятельно (структура, сетка и палитра описаны в комментариях `style.css`).
